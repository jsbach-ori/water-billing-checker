# 水道料金 照会・検算ツール

東京都23区の水道・下水道料金（2か月分）を計算し、水道局に電話で聞いた金額と照合して、結果をPDFで残すWebツールです。不動産管理の業務で、物件ごとの水道料金を照会・検算する作業を短くするために作りました。

- 公開URL：https://jsbach-ori.github.io/water-billing-checker/
- 動作環境：Chrome・Edge（PC）。インストール不要。ログイン不要
- **同梱しているデータはすべて架空です。** 実在の人名・お客様番号・住所は入っていません。公開デモ版なので、実在の個人情報は入力しないでください

## できること
- **料金確認**：物件を選ぶと、お客様番号などの電話で伝える情報が表示されます。期間と使用水量を入れると、料金（水道・下水道・合計、税込）を計算します。水道局の金額と合っていれば［一致］、違えば［違う］を押して金額を入れます。差額と判定（一致／差異あり／未入力／期間エラー）は、契約ごとと建物合計で表示します
- **PDF保存**：ブラウザの印刷機能で保存します。ファイル名は `V001水道20260820-1020（3件）.pdf` の形で自動で付きます
- **作業時間の計測**：物件を選ぶと計測が始まり、PDFを保存すると記録されます。手作業の時間も入力でき、改善前後の差と削減率を表示します。記録はCSVで出力できます
- **物件マスタ**：物件・契約の追加・編集・削除・並べ替えができます
- **料金表・設定**：料金表の表示と出典、消費税率、自分の電話番号、基本料金無償化の入力欄の表示を設定できます

入力した内容は、ブラウザの localStorage にだけ保存されます。外部への通信はありません（CDN・外部フォント・アクセス解析も使っていません）。

## 料金の計算
- 東京都水道局・東京都下水道局の料金表（23区・一般用）に基づきます。単価は `js/rates.js` にまとめています
  - 東京都水道局 料金表（23区）：https://www.waterworks.metro.tokyo.lg.jp/tetsuduki/ryokin/keisan_23
  - 東京都下水道局 料金表：https://www.gesui.metro.tokyo.lg.jp/living/fee/keisan/ryokinhyo
- 2か月分の使用水量を2か月に分けて計算し、端数は切り捨てます。消費税は整数で計算します
- 口径30mm以上の単価は、公式の料金表（結合セル）から読み取った値です
- 日割り計算（月の途中で使用開始・中止した場合）には対応していません

## ローカルで動かす
ES Modules を使っているので、`file://` では動きません。ローカルサーバーを使います。

```
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。ビルドは不要です（素のHTML・CSS・JavaScript）。

## テスト
Node.js 22以降で、次のコマンドを実行します。

```
node --test
```

- `tests/fixtures/cases.json`：計算・判定・ファイル名の期待値（38件）。Excel版（`docs/reference/`）と東京都の公式の計算例で確かめた値です
- そのほかのテスト：入力値の変換、確認状態、作業時間、物件マスタ、外部通信がないことの静的チェックなど
