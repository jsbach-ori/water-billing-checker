# 建物合計の列：一部の契約だけ内訳を確かめたときの表示（案）（2026/11/03 16:20）

まだ実装していません。承認をいただいてから着手します。M1の計算・判定ロジック（`calc.js` の `sumBuilding`・`judgeBuilding`・`judgeContract`）と、cases.json の38件は変えません。変えるのは、`app.js` で建物合計の列に何を表示するかだけです。

## 1. 今の表示と問題
建物合計の水道・下水道の3つの行は、次のように決まっています。

| 行 | 今の決め方 |
|---|---|
| 水道局の回答 | 回答のある契約だけを合計する。回答のある契約がすべて「内訳も確認」なら「計算額どおり」 |
| 差額（回答－計算） | 差額のある契約だけを合計する |
| 判定 | 「合計で照合」の契約を除いて決める（`buildingPartJudge`） |

このため、一部の契約だけ内訳を確かめると、建物全体を確かめたように読めます。
- 例：V003（5契約）で1件だけチェックすると、建物合計は「計算額どおり／0／一致」になります。
- 一方で、計算結果の行（水道 計算結果）の建物合計は、5契約すべての合計です。そのため、「回答」と「計算結果」で対象の契約の数が違うのに、同じ列に並んでいます。

## 2. 「一部だけ」の決め方（3つの案に共通）
建物の水道（下水道も同じ）について、次の2つが両方あるときを「一部だけ」とします。
- 内訳を確かめた契約（［違う］で内訳を入力、または［一致］＋内訳も確認）
- 合計だけで照合した契約（判定欄が「合計で照合」）

次の場合は、今の表示のままです。
- 全契約で内訳を確かめた場合（ご指示のとおり）
- どの契約も合計だけで照合した場合（今のまま「—」と「合計で照合」）

未確認・再確認が必要の契約があると、今も建物合計の判定は「未入力」になります。この扱いは変えません。

この判定は、新しい純粋関数 `buildingPartScope(evaluations, part)` で決めます。戻り値は `'all'`・`'partial'`・`'none'` で、テストを付けます。

## 3. 案
どの案も、印刷の列幅（5契約で約22mm）に収まるよう、「計算額どおり」（6文字）より短い文字にします。

### 案1：3つの行とも「一部のみ」
| 行 | 一部だけのときの建物合計 |
|---|---|
| 水道局の回答 | 一部のみ（小さなグレー） |
| 差額 | 一部のみ（小さなグレー） |
| 判定 | 一部のみ（小さなグレー） |

- よい点：いちばん単純で、建物全体を確かめたようには読めません。
- 気になる点：内訳を確かめた契約で「差異あり」が出ても、建物合計の判定には出ません（契約の列には出ます）。

### 案2（推奨）：回答・差額は「一部のみ」、判定は差異があるときだけ「差異あり」
| 行 | 一部だけのときの建物合計 |
|---|---|
| 水道局の回答 | 一部のみ（小さなグレー） |
| 差額 | 一部のみ（小さなグレー） |
| 判定 | 確かめた契約に「差異あり」があれば「差異あり」（赤）。なければ「一部のみ」（小さなグレー） |

- よい点：建物全体を確かめたようには読めません。内訳の差異という大事な情報は、建物合計でも目立つまま残ります。
- 「一致」は、全契約で内訳を確かめたときだけ出ます。
- 気になる点：判定の行だけ、条件によって表示の種類が変わります。

### 案3：回答・差額は「—」、判定は「合計で照合」
| 行 | 一部だけのときの建物合計 |
|---|---|
| 水道局の回答 | — |
| 差額 | — |
| 判定 | 合計で照合（小さなグレー。今の「合計で照合」と同じ見た目） |

- よい点：新しい言葉を増やしません。建物全体としては合計で照合した、という意味になります。
- 気になる点：
  - 一部の契約で内訳を確かめたことが、建物合計からは分かりません。
  - 案1と同じく、差異が建物合計に出ません。

## 4. 推奨
**案2**をおすすめします。
- 「一致」は、建物全体を確かめたときだけ出ます。
- 内訳の差異は、建物合計の判定でも赤で目立ちます。
- 文字は「一部のみ」「差異あり」のどちらも4文字です。5契約の印刷の列にも1行で収まる見込みです。

**あわせて決めていただきたいこと（案2・案1の場合）**
- 表の下の注記に、一部だけのときにだけ、次の一文を加えるか
  - 「建物合計の水道・下水道は、内訳を確かめた契約が一部だけのため、回答と差額を合計していません。」
  - 加えると、印刷が1〜2行高くなります。
  - 加えなくても「一部のみ」で意味は伝わると考えるので、**加えない**ほうをおすすめします。
