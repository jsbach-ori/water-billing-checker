## Y：計算額の「円」だけが次の行に落ちる
**原因**
- 印刷では、すべてのセルに「どの文字の間でも改行してよい」（`word-break: break-all`）という設定が効いていました。
- そのため、5契約で列が狭いときに「1,232」と「円」の間で改行されていました。

**直し方**
- 金額と「円」をひとかたまりにして、途中で改行しないようにしました（`.nowrap`）。「水道」「下水道」「合計」の文字も同じです。
- 折り返しが必要なときは、「水道」と金額の間でだけ改行します。
- 印刷の計算額の文字を少し詰めました。
  - 水道・下水道は8.5pt（下限の範囲内）
  - 合計は9.5pt
- 見積もりでは、5契約の列（約22mm）に「下水道 1,232円」「合計 23,636円」が1行で収まります。
- ［違う］のときの「差額（回答－計算） +100円」も、金額と「円」を分けないようにしました。

## W：内訳（水道・下水道）も一致を確認した
承認いただいた案（`20261031-1711-W-内訳の確認-案.md`）のとおりに作りました。決めていただきたい点1〜4は、提案どおりです。

**ご指示による変更**
- 内訳も確認した契約では、結果の表と印刷の「水道局の回答」の水道・下水道の欄に、「計算額どおり」と表示します（数字は出しません）。
- 差額は0のままです。
- 判定と照合方法の計算は案のままで、変えたのは表示だけです。

**保存**
- 合計の確認（`confirm`）とは別に、`confirmParts: null | { basis }` を保存します。
- 次のどれかに当たる保存データは、null（内訳は未確認）として読み込みます。
  - `confirmParts` がない旧データ
  - 形が正しくない
  - 合計の確認が「一致」でない
  - 計算条件が合計の確認と違う

**判定**
- 内訳も確認したときだけ、水道・下水道の回答として計算額を `judgeContract` に渡します（`evaluateRow` の中だけの変更）。
- その結果、判定と照合方法は次のようになります。
  - 水道・下水道の判定：一致
  - 総合判定：一致
  - 照合方法：内訳も照合
  - 差額：0

**画面**
- 確認のセルの状態表示の下に、チェック欄「内訳（水道・下水道）も一致を確認した」を置きました。
  - チェック欄の下に、小さなグレーの文字で「ホームページや電話で確かめた場合だけ」と添えています。
  - 押せるのは「一致」のときだけです。それ以外は灰色で押せません。
- チェックすると、状態の表示が「一致（内訳も確認）」になります。
- 凡例の「任意」に「内訳の確認」を加えました。

**状態の変わり方**
- 計算条件が変わると、内訳の確認も一緒に失効し、「再確認が必要」になります。
- ［違う］を押すと、内訳の確認は消えます。
- 次の場合は、［一致］を押し直しても内訳は未確認のままです。改めてチェックが必要です。
  - ［違う］から［一致］に戻したとき
  - 「再確認が必要」から［一致］を押したとき
- 同じ条件のまま［一致］を押し直した場合は、内訳の確認を残します（案の表になかった操作なので、うっかり消えないほうを選びました）。

**Tab順**
- ［違う］の次に、チェック欄が入ります。押せないときは飛ばします。
- チェックの切り替えは、スペースキーでできます。

**建物合計の列の「水道局の回答」**
- 回答のある契約が、すべて内訳も確認した契約のときは、「計算額どおり」と表示します。
- ［違う］で聞き取った内訳の金額がある契約が混ざるときは、今までどおり合計の金額を表示します。

**印刷**
- チェック欄そのものは印刷しません。状態の表示「一致（内訳も確認）」は印刷します。
  - 案では状態とは別に「内訳も一致を確認」と印刷する予定でした。同じ内容になるので、行を増やさないように状態の表示だけにしました。
- 内訳も確認した契約が1件でもあれば、水道・下水道の「水道局の回答」と「差額」の行を印刷します（修正Kの仕組み）。
  - このとき、回答の欄は「計算額どおり」、差額は0です。
  - **この4行の分だけ表が高くなるので、V003 が1ページに収まるかは画面で確かめてください。**
