## 1. 状態の持ち方
**合計の確認（今の `confirm`）とは別に、内訳の確認を保存します。**

```js
// wbc.inquiry の rows[契約ID]
{ ..., confirm: { state: "match", basis },     // 合計の確認（今のまま）
       confirmParts: null | { basis } }         // 内訳（水道・下水道）も一致を確認した（新規）
```
- `confirmParts` は、合計の確認が「一致」のときだけ持てます。
- `basis` には、確認したときの計算条件を、合計の確認と同じ形で記録します。
- 合計の［一致］だけでは `confirmParts` は null のままで、水道・下水道の判定は「合計で照合」です。

**状態の変わり方**（純粋関数 `applyPartsConfirm(row, checked, ev)` を新しく作ります）

| 今の状態 | 操作 | 次の状態 |
|---|---|---|
| 一致（内訳は未確認） | 「内訳も一致を確認した」をチェック | 一致＋内訳も確認（`confirmParts = { basis }`） |
| 一致＋内訳も確認 | チェックを外す | 一致（内訳は未確認） |
| 一致＋内訳も確認 | ［違う］ | 違う（`confirmParts` を消す。今のルールどおり、記録した合計も消す） |
| 違う | ［一致］ | 一致（内訳は未確認。改めてチェックが必要） |
| 一致＋内訳も確認 | 計算条件が変わる | **再確認が必要**（合計の確認と一緒に `confirmParts` も消す＝失効） |
| 再確認が必要 | ［一致］ | 一致（内訳は未確認。改めてチェックが必要） |
| 未確認・違う・再確認が必要・入力エラー・期間エラー | チェック | 何もしない（チェック欄は押せない） |
| すべて | 入力をクリア | 未確認（`confirmParts` も消す） |

**判定に渡す値**（`evaluateRow` の中だけを変えます。`judgeContract` は変えません）
- 一致＋内訳も確認のとき：回答（合計・水道・下水道）として、計算額をそのまま渡します。
- その結果、次のようになります（今の仕組みのまま、この結果になります）。
  - 水道・下水道の判定は「一致」になります。
  - 照合方法は「内訳も照合」になります。
  - 結果の表の「水道局の回答」「差額」の行には、計算額と差額0が出ます。
- 合計の［一致］だけのとき：今のまま、合計だけを渡します。水道・下水道の判定は「合計で照合」です。

**保存データの移行**
- 旧データには `confirmParts` がないので、null（内訳は未確認）として読み込みます。
- 形の正しくない値も、null にします。
- 確認したと推定することはしません。

## 2. 画面の案
入力の表の「確認（合計）」のセルで、［一致］［違う］と状態表示の下に、チェック欄を置きます。

```
 ┌───────────────────────┐
 │ [ 一致 ]  [ 違う ]          │
 │      一致                  │  ← 状態（緑）
 │ ☐ 内訳（水道・下水道）も    │  ← 状態が「一致」のときだけ押せる
 │    一致を確認した           │     （それ以外は灰色で押せない）
 │   ホームページや電話で      │  ← 小さなグレーの説明
 │   確かめた場合だけ          │
 └───────────────────────┘
```
- チェックすると、状態表示が「一致（内訳も確認）」になります。
- 計算結果の表では、次のように変わります。
  - 水道・下水道の判定が「一致」（緑）
  - 照合方法が「内訳も照合」
  - 「水道局の回答」の行に計算額
- ［違う］のときは、このチェック欄の代わりに、今までどおり「内訳（水道・下水道）も聞いた場合」の入力欄を使います。役割を分けるためです。
- 「再確認が必要」になったときは、チェックが外れた状態で表示し、［一致］をもう一度押すとチェックできるようにします。
- 色：チェック欄は「任意」の白です（凡例の任意の項目に「内訳の確認」を加えます）。

## 3. Tab順
今の順番：開始日 → 終了日 → 使用水量 →（無償化）→［一致］→［違う］→（開いていれば）水道局の合計 → 内訳の開閉 → 水道 → 下水道

変更後：［違う］のあとに**チェック欄**を入れます。
- 開始日 → 終了日 → 使用水量 →（無償化）→［一致］→［違う］→ **内訳も一致を確認した** →（違うのとき）水道局の合計 → 内訳の開閉 → 水道 → 下水道 → 次の契約
- チェック欄が押せないとき（一致以外）は飛ばします（今の仕組みのとおり、無効な要素は飛ばします）。
- スペースキーでチェックを切り替えられます。
