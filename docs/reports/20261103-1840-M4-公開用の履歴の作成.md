### 4. pushで公開されるブランチが main だけであること
- 今のローカルのブランチは、`main`（公開用）と `dev-history`（非公開）の2つだけです。タグとstashはありません。
- リモートはまだ設定していません。
- **誤操作を防ぐ設定**
  - `dev-history` のpush先を、存在しない名前にしました（`branch.dev-history.pushRemote`）。
  - これで、`dev-history` を選んだまま `git push` しても失敗します。
  - ただし、`git push origin dev-history` のようにブランチ名をはっきり指定すると送れてしまいます。完全に防ぐ設定ではありません。
- **pushするときの手順**（許可をいただいてから行います）
  1. `git remote add origin <URL>`
  2. `git config remote.origin.push refs/heads/main:refs/heads/main`
     - これで、`git push origin` で送られるのは main だけになります。
  3. `git push -u origin main`
     - main だけを指定して送ります。`--all`・`--mirror`・`--tags` は使いません。
  4. pushのあと、`git ls-remote origin` で、リモートにあるのが main だけであることを確かめます。
- **以後の開発**：新しい main の上に積み上げます。`dev-history` には加えません。古い履歴との比較は手元で行います。
