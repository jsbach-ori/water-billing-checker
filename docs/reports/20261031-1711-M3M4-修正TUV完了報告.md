## T：印刷で使用水量が右の列にずれる不具合（最優先）

### 原因
- 画面用のスタイル `.grid input[type="text"] { min-width: 110px; }` が、印刷のときにも効いていました。
- V003（5契約）の印刷では、契約の列は約28.8mmで、セルの中は約100px です。入力欄は最低でも110pxあるので、セルより広くなり、右へはみ出していました。
- 使用水量の欄は右寄せなので、数字が入力欄の右端、つまり罫線を越えた右隣の列の左端に描かれていました。最後の列では、用紙の端で切れていました。
- 開始日・終了日は左寄せなので、文字はセルの中に描かれ、ずれは目立っていませんでした。ただし、欄そのものは同じようにはみ出していました。

### 直し方
次の2つを行いました。
1. **入力欄そのものを印刷しないようにしました。**
   - 印刷の直前（`beforeprint`）に、料金確認のすべての入力欄の値を、同じセルの中の印刷用の文字に写します。
   - 対象は、開始日・終了日・使用水量・回答額（合計・水道・下水道）・問い合わせ日・対応者メモです。
   - 印刷用の文字はセルの幅で折り返すので、セルの外に出ることはありません。数値は右寄せです。
   - これで、入力欄の幅や描き方とは関係なく、値は必ず自分の契約のセルに収まります。
2. 画面用の `min-width: 110px` も、`0` に直しました。

### 確かめたこと（自動）
V002・V001・V003 の3つで、画面の部品を文字として組み立て、構造を確かめました。
- 文字の入力欄はそれぞれ7・19・31個あり、すべての直後に印刷用の文字の置き場所があります。
- 対応者メモにも、印刷用の文字の置き場所があります。

## U：上下の表で契約の列の位置をそろえる
- 次の3つの表を、どれも「項目の列＋契約1〜5の列＋右端の列」の**7列**にしました。
  - 入力の表（契約情報と照会結果の入力）
  - 計算結果の表
  - 内訳の表
- 右端の列は、計算結果の表では「建物合計」です。入力の表と内訳の表では、**罫線も文字もない空の列**にしました。
- 列の幅は、3つの表で同じ値を使います。

  | | 項目の列 | 契約の列と右端の列 |
  |---|---|---|
  | 画面 | 210px | 150px |
  | 印刷 | 46mm | 残りを等分 |

- 印刷で契約が無い列を出さない仕組みは、3つの表で同じ列が消えるので、位置はそろったままです。
  - 確かめた結果：契約の無い列は、V002 では4列、V001 では2列、V003 では0列で、入力の表と計算結果の表で同じでした。どの物件でも、すべての行が7列でした。
- 画面では列の幅が固定になったので、契約の見出しは列の中で折り返すようにしました（ラベル「お客様番号」が番号の上に回ることがあります）。
- **ページ数への影響**：入力の表にも右端の列が加わったので、印刷では入力の表の契約の列が少し狭くなります。
  - 5契約では、28.8mmから24mmになります。
  - 計算結果の表と同じ幅になるので、前回期間や計算額の折り返しが増え、入力の表が少し高くなる見込みです。
  - 前回は3物件とも1ページでしたが、このためページ数が変わるおそれがあります。下の確認項目で見てください。
